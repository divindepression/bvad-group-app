## ✨ Fonctionnalités actuelles

- 🔐 Authentification JWT avec rôles
- 🏢 Multi-filiales avec sélecteur coloré
- 📱 Responsive (mobile-first)
- 🎨 Design pro Tailwind CSS
- 🐘 Base PostgreSQL
- 📖 Documentation API avec Scalar
- 🐳 Déploiement Docker

---

## 🛠 Stack technique

**Frontend** : Angular 18 · Tailwind CSS · SCSS · RxJS · Signals  
**Backend** : ASP.NET Core 9 · Entity Framework Core · JWT · BCrypt  
**Base** : PostgreSQL 17  
**Deploy** : Docker + docker-compose

---

## 🚀 Installation avec Docker

```bash
git clone https://github.com/divindepression/bvad-group-app.git
cd bvad-group-app
cp .env.example .env
docker compose up --build
```

Puis :
- 🎨 Frontend : http://localhost:4200
- 🔗 API : http://localhost:5051/scalar
